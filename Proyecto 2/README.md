Proyecto 2 — Ray Tracer

Estructura creada:
- `assets/`  -> pon aquí `reference.jpg`, texturas (jpg/png), envmap y OBJ(s).
- `outputs/` -> renders finales y previews.
- `docs/scene_plan.md` -> plan de escena y composición (editable).

Cómo usar (rápido):
1. Copia/pega la imagen de referencia en `Proyecto 2/assets/reference.jpg`.
2. Copia texturas y OBJ(s) en `Proyecto 2/assets/`.
3. Abre `raytracer_scene.py` (en el workspace raíz) y ajusta rutas de assets si es necesario.
4. Ejecuta el script de render (por ejemplo `python raytracer_scene.py`) desde la carpeta del proyecto.

Notas:
- Si tu `model.py` no soporta UVs/MTL, colóca objetos simples como primitivas o dame permiso para implementar un loader OBJ compatible.
- Para envmap, añade `envmap.jpg` a `assets/` y actualiza la ruta en el archivo de escena.

Contacto: agrega aquí cualquier asset y dime si quieres que implemente el loader OBJ o materiales.
